How it works

What this page does

It is the routine, running in the browser. Drop the raw TMX export and it produces the same ten-sheet workbook the Python script produces — same thresholds, same detection logic, same column order. No Python, no Databricks, no install. It works offline from the shared drive.

The output was checked cell by cell against the Python routine on the same input. All ten sheets came back identical.

The ten sheets

  • All Registrations — every row, with a risk score, risk level, the reasons behind the score, and any shared-signal gang IDs.
  • Bot Clusters BSH / CH — accounts whose email follows a generated pattern, sharing a browser or canvas fingerprint, registered inside a 24-hour window.
  • IPs / True IP / DOB / Phone / Postal Code / DNS IP — accounts sharing an attribute. IP and phone match on the first 80% of the value, so near-misses still group.
  • Potential Gangs — the naming-pattern analysis, scored by cohesion.

Risk scoring

Each registration collects points for proxy or VPN use, remote desktop, hosting or datacenter IPs, proxy routing, risky email results and TMX's own flags, capped at 100. The TMX policy score adds up to 25 more. Anything at 70 or above is HIGH, 40 to 69 is MEDIUM.

Reading a cohesion score

Cohesion measures how alike the names are inside one group, out of 100: 40 points for a shared email shape, 25 for the username matching the email, 20 for a shared alphabetic affix, 15 for a repeated digit token.

Below 38
Noise. Names overlap by chance.
38 to 64
Worth a look, especially when the group is large.
65 and above
A naming factory. The accounts came from one template.

Why fingerprints alone are not enough

Serious operations rotate device fingerprints between registrations, so grouping on browser hash alone misses them. The naming-pattern pass catches the shape of the names regardless of which device produced them.

If something goes wrong

  • Nothing detected: check the export has Account Login and Account Email columns. Without those, gang detection cannot run.
  • Broken accents: re-save the CSV as UTF-8 from Excel.
  • Very large files: the browser holds the whole file in memory. Above roughly 100,000 rows, split the export or fall back to the Python script.
  • Semicolons and commas are both handled — the delimiter is detected from the first line.
